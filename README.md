# ZMD04

批量查询物料 MD04 程序。

- **程序名**：ZPP_MD04_COPY
- **REPORT 对象**：`zpp_md04_copy`
- **模块**：PP/MM（MRP）
- **源码位置**：`src/zpp_md04_copy.abap`

## 功能说明

参考事务码 **MD04**（库存/需求清单）功能，实现多个物料的物料需求计划清单批量查询。通过 BAPI `BAPI_MATERIAL_STOCK_REQ_LIST` 获取需求数据，支持并行处理（RFC 多线程）提升大批量物料的查询效率，并以 ALV 展示每个物料的需求计划段信息。

## 选择屏幕参数

| 参数 | 说明 |
|------|------|
| `S_MATNR` | 物料号 |
| `S_WERKS` | 工厂（默认 `2C40`，必填） |
| `S_BERID` | MRP 范围（默认 `2C40`） |
| `S_AUSKT` | 例外消息 |
| `S_DAT00` | 收货/需求日期 |
| `S_DISPO` | MRP 控制者 |
| `P_PLUMI` | 收货/发货标识过滤（可选） |

## 运行前提

- 物料主数据（`MARA`/`MARC`）与物料需求计划数据已维护
- 若启用并行处理，需在 RZ12 中配置服务器组，并设置并发进程数（程序内 `g_wp` 参数）

## 部署步骤

1. 使用事务码 **SE38** 创建程序，将 `src/zpp_md04_copy.abap` 源码粘贴保存并激活
2. 运行程序，输入物料号、工厂等条件
3. ALV 输出各物料的需求计划清单
